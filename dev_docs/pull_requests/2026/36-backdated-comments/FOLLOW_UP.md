## Open

- **OBSERVATION: the comment card's actions are invisible on touch devices.**
  Edit and Delete (behind the kebab) and Reply are `opacity-0` until
  `:hover` / `:focus-within` / `:focus-visible`
  (`comments_component.ex:1374`, `:1640`; the decoration pencil at `:1489`
  predates the PR and does the same). Touch devices never match `:hover`, so on
  a phone these controls are present and tappable but invisible until you
  already know where to tap.

  The review declined to change it on the grounds that it matches an existing
  convention in the same file rather than being a regression the PR
  introduced — which is a fair reading of *that PR's* scope, but leaves the
  behaviour live. Raised with Max because it is a design call, not a defect,
  and because it cuts against his standing instruction to check narrow screens
  ("don't forget about narrow screens like phones and all that", 2026-08-27).

  Options if it should change: drop the opacity gate under a
  `@media (hover: none)` block so the controls are simply always visible on
  touch, or keep the reveal on pointer devices only. Both are a few lines and
  neither affects the desktop appearance.
